# ملاحظات الاتصال ببوابات الرسائل

## المعمارية الحالية

- التطبيق هو المسؤول عن إعداد الحملات، حفظها محلياً، جلب المستلمين، وإرسال الرسائل.
- تُحمّل إعدادات البوابة وتفضيلاتها من Supabase مباشرة باستخدام جلسة المستخدم وRLS.
- يتصل التطبيق مباشرة بعنوان البوابة المحفوظ. لا يمر الإرسال أو جلب المشتركين عبر Supabase Edge Functions.
- تُحلل ملفات CSV وPDF على الجهاز. يستخدم استيراد الحملات خدمة تحليل المستندات لملفات Excel؛ يجب أن تعيد كل الصفوف، ولا تُستخدم عينات الخادم كقائمة مستلمين.
- في وضع القالب، تُركّب رسالة مستقلة لكل سجل من نص القالب بعد استبدال متغيراته ببيانات السجل.
- عمود الرسالة الجاهزة مسار بديل مستقل؛ عند اختياره يُستخدم نصه بدل نص القالب، ولا يغيّر تعريف القالب.
- يرسل `DocumentImportModal` ملفات Excel إلى عنوان FastAPI المحفوظ. لا يحتوي هذا المستودع على مشروع Python أو تطبيق endpoint؛ التنفيذ الخارجي مطلوب لهذا المسار.
- تحليل PDF محلي في إنشاء القالب واستيراد الحملات، ويستخدم المساران محلل PDF ووثيقة النص والإحداثيات نفسها. لا يُرفع PDF إلى FastAPI.

## القالب واستخراج الرسائل من المستند

القالب ليس رسالة ثابتة تُستخرج كما هي من الملف. هو تعريف لكيفية تحويل سجل المستند المتوافق إلى رسالة:

1. **نص الرسالة (`body`)** هو المحتوى الذي سيصل للمستلم، ويمكن أن يحتوي متغيرات مثل `{{اسم_المشترك}}` و`{{المبلغ}}`.
2. **ربط المتغيرات (`variable_mappings`)** يحدد مصدر قيمة كل متغير: عمود في CSV/Excel أو منطقة نص محددة في PDF. ويمكن أن تعني منطقة PDF قيمة واحدة لكل صفحة أو قيمة لكل صف داخل عمود جدول. يحفظ التطبيق هذا الربط مع القالب ويعرضه عند استيراد مستند لاحق.
3. عند اختيار قالب، يطابق التطبيق متغيراته مع أعمدة المستند، ويتيح للمستخدم تغيير أي ربط غير مناسب. حقول PDF التي يقترحها التحليل الآلي ليست نهائية؛ يستطيع المستخدم تحديد موضع بديل من معاينة PDF. واختيار نص من القائمة في نمط الصفوف يحدد موضع العمود فقط؛ يجب سحب نطاق صفوف البيانات صراحةً قبل اعتماد الربط. يستخدم التحليل والمعاينة وثيقة النص المشتركة نفسها، ثم يعاد تطبيق المنطقة المحفوظة على المستند المتوافق.
4. يمكن الجمع بين حقول PDF المستخرجة آليًا على مستوى الصفحة وحقول مناطق الصفوف؛ تُكرر قيمة العمود الآلي لكل صف تابع للصفحة نفسها، بينما تبقى قيم مناطق الصفوف خاصة بكل سجل.
5. تُنشأ رسالة لكل سجل/صف في CSV/Excel، أو لكل صفحة/صف PDF وفق نمط الربط، باستبدال المتغيرات بقيم ذلك السجل. تُعرض الرسائل للمراجعة قبل الإرسال، وينفذ `renderMessage` الاستبدال محليًا.

مثال: إذا كان نص القالب `عزيزي {{اسم_المشترك}}، المبلغ المستحق {{المبلغ}} ريال.` وربط `اسم_المشترك` بعمود الاسم و`المبلغ` بعمود المبلغ، ينتج التطبيق رسالة بقيم كل صف. توافق المستند يعني أن بياناته تحتوي المصادر المطلوبة أو أن تخطيط PDF يسمح بإعادة استخدام المناطق المحفوظة؛ لا يعني أن كل ملف سيُطابق تلقائيًا دون مراجعة.

في وضع **الرسالة الجاهزة** فقط، يمكن للمستخدم اختيار عمود يحتوي نص الرسالة كاملًا. عند اختيار وضع **حسب القالب** يتجاهل التطبيق هذا العمود ويُنشئ النص من `body` والقيم المربوطة.

## إدارة إعدادات البوابة

يقرأ التطبيق سجلات المستخدم من `gateway_connections` و`gateway_settings` باستخدام Supabase Client. تقيد سياسات RLS الوصول إلى سجلات المستخدم المصادق عليه. تتضمن بيانات الاتصال عنوان HTTPS واسم المرسل ومفتاح API.

لأن الإرسال مباشر، يصل مفتاح API إلى ذاكرة التطبيق ويُرسل إلى البوابة فقط في ترويسة `Authorization`. لا يمكن اعتبار المفتاح سراً عن مالك الجهاز أو عن نسخة تطبيق معدّلة؛ يجب قصر الصلاحية والحصة في إعدادات البوابة، وتدويره عند الاشتباه بكشفه.

## عقد الاتصال بالبوابة

### جلب المستلمين

يطلب التطبيق `GET` إلى عنوان البوابة مع:

```http
Authorization: Bearer <api-key>
Accept: application/json
```

تُقبل قائمة مباشرة أو قائمة ضمن `data` أو `subscribers`. لكل عنصر يلزم حقل هاتف أو بريد إلكتروني، ويمكن توفير الاسم والرسالة الجاهزة.

### إرسال رسالة

يرسل التطبيق `POST` مستقلاً لكل مستلم، مع الترويسات السابقة وإضافة `Content-Type: application/json`، والحمولة:

```json
{
  "sender": "اسم المرسل",
  "to": "+966500000000",
  "message": "نص الرسالة"
}
```

تعني استجابة HTTP من فئة 2xx قبول البوابة للطلب. يعاد فقط على أخطاء الشبكة و`429` و`502` و`503` و`504`، مع احترام `Retry-After` والتأخير التدريجي المحلي. تحفظ حالات الرسائل والتقدم في SQLite على الجهاز.

## قيود المنصات والنشر

- تطبيقات Android وiOS تتصل مباشرة بالبوابة؛ لا حاجة إلى CORS لطلبات تطبيقات الهاتف الأصلية.
- نسخة الويب تحتاج أن تسمح البوابة بطلبات CORS من نطاق التطبيق، وإلا يفشل الاتصال من المتصفح.
- تم إيقاف `hoodhad-send` و`gateway-settings` كمساري إرسال وإدارة خادميين؛ تعيدان `410 Gone` بعد نشر النسخ الحالية. يجب نشر التغيير إذا كانت النسخ القديمة منشورة في Supabase.
- يجب إبقاء مفاتيح Supabase العامة فقط في التطبيق، وعدم تضمين `service_role` أو أسرار الخادم في التطبيق.
