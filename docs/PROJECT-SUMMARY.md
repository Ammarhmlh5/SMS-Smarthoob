## 2. الميزات الذكية المُنفذة (Smart AI & Heuristics)

### 2.1 اكتشاف تلقائي للأعمدة (Auto Column Detection)
- تحليل محتوى الملفات (CSV / Excel / PDF) واكتشاف أنواع الأعمدة:
  - **رقم الهاتف**: تمييز الأرقام البادئة بـ `+`، `00`، `05`، أو `966`.
  - **الاسم**: تمييز الأعمدة التي تحمل دلالات الاسم (`الاسم`, `اسم العميل`, `name`, `customer`).
  - **المبلغ**: تمييز الحقول المالية والأرقام العشرية والريال.
  - **تاريخ الاستحقاق**: تمييز صيغ التواريخ.
- إسناد نسبة ثقة (`confidence score`) لكل عمود.

### 2.2 اقتراح تلقائي ومطابقة للمتغيرات (Auto Variable Linking)
- مقارنة متغيرات القالب (مثل `{{الاسم}}` و `{{المبلغ}}`) بأسماء وأنواع أعمدة الملف.
- مطابقة جزئية وتامة ذكية مع مراعاة اللغة العربية والإنجليزية وتطبيع النصوص.
- تعيين تلقائي لأكثر الأعمدة ملاءمة مع إمكانية التعديل اليدوي من قبل المستخدم.

### 2.3 المعاينة الذكية للرسائل (Smart Message Preview)
- توليد نص الرسالة المخصص لكل مشترك في الوقت الفعلي.
- كشف الحقول الناقصة وتحديد السجلات غير الصالحة قبل الإرسال.

## 3. معمارية الـ Offline-First والتزامن السحابي

1. **العمل المستقل دون اتصال (Offline Support)**:
   - يتم تخزين القوالب، الحملات، إعدادات البوابات، وسجلات المشتركين في قاعدة بيانات `expo-sqlite` محلية على الجهاز.
   - 7 قوالب افتراضية جاهزة مدمجة مع التطبيق للقراءة الفورية.
2. **سجل المزامنة (Sync Engine)**:
   - أي عملية إنشاء أو تعديل أو حذف تُسجل في جدول `sync_log` محلياً مع حالة `pending`.
   - عند توفر الاتصال بالإنترنت، يقوم المحرك برفع التغييرات وجلب التحديثات السحابية من Supabase تلقائياً أو عبر زر المزامنة اليدوية في الإعدادات.
